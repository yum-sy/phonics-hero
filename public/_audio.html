각 소리를 눌러 들어보고 OK 또는 NO 를 눌러라. 판정은 저장소의 sound-verdicts.json 에 바로 기록된다. file = 미리 생성된 음소 파일, tts = 엔진 합성.

모음 aaa ihh eh uh awh 다섯 개를 특히 주의해서 들어라. 생성기는 "모음이다" 와 "다른 단어에서도 같게 나온다" 까지만 증명할 수 있고, 그게 /ɛ/ 인지 /ɪ/ 인지는 증명하지 못한다. 잘못 골랐다면 거기에 숨는다.
